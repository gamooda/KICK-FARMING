# Twitch Farming

Нативное настольное приложение для автоматического сбора Channel Points и бесплатных Twitch Drops.

## Технологии

- Python 3.11.
- PySide6-Essentials (Qt6) для интерфейса.
- Отдельный backend для Twitch API, авторизации, инвентаря, кэша и автообновления.
- Qt thread pool для фоновых задач интерфейса.

Нативный интерфейс Qt6 работает без внешнего браузерного runtime.

## Запуск

Открой Twitch Farming.exe из GitHub Releases или запусти start.bat.

При первом подключении введи логин Twitch и подтверди авторизацию на официальной странице. Пароль Twitch приложение не запрашивает и не сохраняет. Авторизационная сессия хранится отдельно от настроек и шифруется средствами Windows DPAPI для текущего пользователя. Каналы и переключатели сохраняются в JSON в %APPDATA%\Twitch Farming\config.json.

## Структура

- `app.py` — точка входа.
- `qt_app.py` — нативный интерфейс Qt6.
- `backend.py` — Twitch API, состояние, Drops, кэширование и обновление.
- `engine/` — движок Channel Points Miner.
- `requirements.txt` — зависимости.

## Сборка

GitHub Actions проверяет Python-код и Qt-интерфейс, собирает Windows EXE через PyInstaller и публикует архив в Releases. Версия приложения задаётся константой `APP_VERSION` в `version_info.py` и отображается в интерфейсе.
