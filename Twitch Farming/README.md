# Twitch Farming

Графический клиент для автоматического учёта просмотра и получения доступных наград Twitch.

## Запуск

Открой Twitch Farming.exe из GitHub Releases или запусти start.bat.

Введи логин Twitch и список каналов. Нажми «Запустить». При первом входе приложение откроет официальную страницу Twitch: введи показанный в программе код и подтверди вход.

Пароль Twitch приложение не запрашивает и не сохраняет. Авторизационная сессия хранится отдельно от настроек и шифруется средствами Windows DPAPI для текущего пользователя. Каналы и переключатели сохраняются в JSON в %APPDATA%\Twitch Farming\config.json.

## Интерфейс

В окне отображаются активные каналы, количество полученных за сессию баллов и короткая лента событий. Технические сообщения и подробные строки движка в интерфейс не выводятся.

## Сборка

GitHub Actions собирает Twitch Farming.exe для Windows и публикует его в Releases после изменений в этой папке.
